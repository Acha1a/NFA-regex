# NFA Regex EngineA regular expression engine built from scratch using Thompson's NFA construction.No `std::regex` — everything is implemented manually.## Features- Literals (`abc`)- Dot — any character (`.`)- Star — zero or more (`a*`)- Alternation (`a|b`)- Grouping (`(ab)*`)- Escaping (`\.`, `\*`)## How it works1. Pattern is parsed into an **NFA** using **Thompson construction**.2. Each operator becomes a small NFA fragment.3. Fragments are connected via **epsilon transitions**.4. Simulation tracks the **set of active states** and computes epsilon-closures.Complexity: O(n ? m), where n = input length, m = pattern length.## BuildRequires a C++17 compiler.With MSVC:\`\`\`cl /EHsc /std:c++17 /Fe:nfa_tests.exe nfa.cpp test_nfa.cppcl /EHsc /std:c++17 /Fe:nfa_demo.exe nfa.cpp main.cpp\`\`\`With g++:\`\`\`g++ -std=c++17 -O2 nfa.cpp test_nfa.cpp -o nfa_testsg++ -std=c++17 -O2 nfa.cpp main.cpp -o nfa_demo\`\`\`## Run tests\`\`\`nfa_tests.exe\`\`\`## Limitations- `+` and `?` quantifiers are not yet supported.- No character classes `[abc]`, no anchors `^ $`.- Empty pattern is rejected with an error.## LicenseMIT
